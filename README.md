### 1. 🤖 Autonomous Agents & State Machine Workflows
- Multi-step reasoning loops built with **LangGraph** and **LangChain**.
- State graph routing that classifies user intent and dispatches tasks to dedicated execution subgraphs.
- Deterministic guardrails and Human-in-the-Loop (HITL) approval steps for high-stakes or destructive operations.

### 2. 🔌 Model Context Protocol (MCP) Ecosystems
- Standardized **FastMCP** servers exposing live business databases and backend services directly to LLM clients (Claude Desktop, IDE agents, custom frontends).
- Tool, Resource, and Prompt definitions enabling bidirectional interactions between human operators and AI agents over a single source of truth.

### 3. 📚 Production RAG & Knowledge Retrieval
- Intent-routed vector retrieval over persistent **ChromaDB** collections to prevent cross-domain context contamination.
- Automated document ingestion pipelines with semantic chunking and local embeddings (**Ollama**).
- Quantitative evaluation suites measuring intent classification accuracy, retrieval recall, and abstention behavior on unsupported queries.

### 4. ⚡ Full-Stack APIs & Cloud Services
- High-throughput backend services using **FastAPI**, **Pydantic** data contracts, and relational persistence (**MySQL**, **SQLite**).
- Containerized workflows with **Docker** and cloud deployments on **Render** with live monitoring and Server-Sent Events (SSE).

## 📐 Engineering Philosophy

1. **Deterministic Tool Use Over Hallucination:** Agents should follow strict Pydantic schemas, typed parameters, and explicit intent classifications before executing mutations.
2. **Context Isolation:** In multi-domain knowledge bases, partition vector spaces to eliminate cross-domain hallucination and contamination.
3. **Safety & HITL:** Always gate destructive or high-impact actions (e.g., long hours, financial records, database writes) behind human confirmation loops.
4. **Empirical Benchmarking:** Every LLM workflow must be backed by measurable metrics — classification accuracy, keyword recall, and abstention rates verified by automated test suites.
